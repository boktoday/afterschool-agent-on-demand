## Publishing your own version

1. Clone this repo:
   ```bash
   git clone https://github.com/boktoday/afterschool-agent-2.git
   cd afterschool-agent-2
   ```

2. Edit `index.html` to suit your programme (price, schedule, contact info, etc.)

3. Publish to [here.now](https://here.now):
   ```bash
   curl -fsSL https://here.now/install.sh | bash
   ~/.claude/skills/here-now/scripts/publish.sh ./index.html \
     --title "Your Programme Name" \
     --description "One-line description for the viewer."
   ```

   You'll get a live URL on `https://<auto-generated-slug>.here.now/` plus a
   claim URL to attach it to your account.

This landing page is for the **Afterschool Agent** programme — a 4-week

2. **Body as Temple** — taking care of the only vehicle you get
3. **Scripture & Wisdom** — tested convictions from your tradition
4. **Nature Connection** — going outside, under sky, in air
5. **Digital Self-Defence** — knowing what you give away when you click "agree"
6. **Life Skills** — feeding, fixing, building things
7. **Real Community** — people who'd call you at 2am
